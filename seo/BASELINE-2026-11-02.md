## Site issues found
- /book-snagging/ served the homepage title and a canonical pointing at the homepage, so Google treats it as a copy of the home page.
- Blog posts returned HTTP 404 (served by the 404 fallback), so Google will not index them.
- Every page is an empty `<div id="root">` until JavaScript runs; AI crawlers that do not run JS see no content.
- Schema had a self-written review count (not eligible for stars, against Google policy) and no phone number.
